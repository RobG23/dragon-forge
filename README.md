# Dragon Forge

One-player dragon-curve hatchery. Fold Heighway, twindragon, terdragon, Lévy C and mutant-angle wyrms in the browser.

## Play now

- Instant CDN: https://cdn.jsdelivr.net/gh/RobG23/dragon-forge@main/index.html
- HTML preview: https://htmlpreview.github.io/?https://github.com/RobG23/dragon-forge/blob/main/index.html
- After you enable Pages (below): https://robg23.github.io/dragon-forge/

## Enable GitHub Pages (permanent URL)

1. Open https://github.com/RobG23/dragon-forge/settings/pages
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. The site is live in about a minute.

## Controls

- Fold / Unfold generations, or drag the generation slider
- Change species and turn angle for variants
- Hatch animate, mirror handedness, save PNG
- Drag to pan, scroll to zoom
- Keys: `+` fold, `-` unfold, `Space` hatch, `M` mirror, `R` recenter
